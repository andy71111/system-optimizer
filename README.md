# 系统优化工具 (System Optimizer)

一个安全的 Windows 系统优化工具（C# WinForms，单 EXE），包含内存清理、存储清理、磁盘清理三大功能。

## 功能特性

### 🧠 内存清理
- 实时显示内存使用率、总内存、可用/已用内存
- 一键回收所有进程的闲置工作集内存
- **不关闭任何程序**，系统关键进程自动跳过，安全可靠

### 🧹 存储清理
- 扫描并清理可再生的临时/缓存文件（用户临时、系统临时、浏览器缓存、缩略图缓存）
- 回收站默认不清理，需单独勾选并二次确认（不可恢复）
- 只清理可再生的缓存，**绝不触碰个人文件**

### 💾 磁盘清理
- 查看各磁盘总容量、已用、可用、使用率（带进度条，超阈值变色提醒）
- 按盘清理临时文件与回收站
- 一键清理所有盘（不含回收站）
- 大文件分析：扫描超过 100MB 的大文件，**仅报告不删除**，由你自行决定

### ⚙️ 其他
- 开机自启开关（注册表 Run 键）
- 深色渐变标题栏、卡片式圆角界面

## 使用说明

1. 下载 `MemoryCleaner.exe` 直接双击运行（需要 .NET Framework 4.8，Windows 10/11 自带）
2. 建议以**管理员身份运行**，可清理更彻底（系统临时文件、回收站）
3. 内存清理建议 5~10 分钟一次；频繁清理反而增加 CPU 开销

## 安全说明

- 内存清理仅回收闲置工作集，不结束进程、不改系统设置
- 存储/磁盘清理只动可再生的临时缓存，不删除个人文件
- 回收站清理不可恢复，工具默认不勾选、清理前二次确认
- 纯本地工具，无联网、无后台行为、无数据上传

## 源码编译

源码为单文件 C# WinForms 程序（`Program.cs`），可使用任意 C# 编译器编译：

```
csc /nologo /target:winexe /platform:anycpu /optimize+ /win32icon:app.ico /out:MemoryCleaner.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll /reference:System.dll Program.cs
```
